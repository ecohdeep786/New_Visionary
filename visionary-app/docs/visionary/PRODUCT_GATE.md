# Head-of-Product gate — operative pointer

Authority: [v2.2 Part AA](VISIONARY_MASTER_v2.2.md), not the archived ten-gate pack. Runs **after 07-QA**, with evidence, after every wave. This file records the checklist, not a pass.

| Gate | Required evidence |
|---|---|
| G1 User job | Purpose and meaningful action per touched screen |
| G2 Next action | One next action, ≤5 Home modules, evidence-backed reasons |
| G3 Context | Correct role/stage vocabulary, active organization boundary |
| G4 Connections | Part F/Z scoped lifecycle and paired-view tests |
| G5 Honesty | Claims, metric definitions, sources and demo disclosure |
| G6 Commercial/safety | Child protection, permitted sponsorship, billing/consent boundaries |
| G7 Continuity | Part H inheritance and clean public visual regression evidence |
| G8 States | Applicable Part O state matrix for touched screens |
| G9 Quality | Tests, console, accessibility, responsive and reduced-motion evidence |
| G10 Handoff | Complete STATUS, DECISIONS, QA and next owner |
| G11 Design inheritance | DESIGN_INVENTORY followed; changes justified, before/after captured |
| G12 Transitions | Part W remapping, atomic audience updates, resume and undo fidelity |

Fail writes `G# / reason / owner` in STATUS. Owner fixes → 07-QA reruns → gate rechecks. Merge remains blocked until all twelve pass and the app runs. PM/source inventory is not gate execution; do not backfill passes for work that predates this protocol.
