## Concrete first connected rehearsal

Use **Where does sodium belong, and why is it different from chlorine?** as the first bounded objective. It draws on pp3-5, with size comparisons from pp6-8 as an extension. This is advanced enrichment if used with a Class 8 learner; it must not appear as verified CBSE Class 8 coverage.

1. **Academy to chapter.** Preserve the learner's selected curriculum and display the supplied source as a separate demo. The chapter card shows the literal title, source status and a single Start/Resume action. Opening it reveals the ordered concepts; do not silently substitute this PDF for an official syllabus.
2. **Teach / Observe.** Show sodium selected in a small periodic-table region. Present a schematic atom labelled 11 protons and neutral electron arrangement 2,8,1. Explain one idea: three occupied shells locate the period; one outer electron connects this main-group example to group 1. Reveal supporting detail on demand.
3. **Teach / Change one thing.** Select chlorine. Update atom labels, the configuration 2,8,7 and the table position together. Ask the learner to notice the unchanged period and changed outer-electron count. Keep the selected element and view when navigating away. No free slider should create an impossible configuration while still labelling it sodium.
4. **Optional prediction.** Before revealing the explanation, offer a short group/period prediction. This exploration is unscored. A wrong prediction reveals an explanation and lets the learner try again; it does not create a failed mastery record.
5. **Ask.** Open the existing contextual Ask route with this learning unit, source revision and objective. Suggested doubt: 'Why are sodium and chlorine in the same period but different groups?' Save an existing draft and offer the suggestion without overwriting it. An unconnected model must show the actual unavailable state; authored help must be labelled as authored help.
6. **Check understanding.** New authored MCQ: a neutral atom has arrangement 2,8,7; which position fits this main-group example? Key: period 3, group 17. Distractors should distinguish swapped group/period, shell-count error and outer-electron-count error. Retain exact question/version and selected answer. A wrong answer offers the relevant shell explanation before retry.
7. **Practice.** Transfer to a different atom: arrangement 2,8,2 corresponds to period 3, group 2. A second optional comparison asks whether Li or Na has more occupied shells and why. Present one question at a time. These questions need authored answer keys in the application's supported question format.
8. **Build.** After the existing comprehension and practice gates pass, open a private guided artifact titled 'My element comparison guide'. The student adds two labelled configurations, explains their table positions, records one supported comparison and describes a model limitation. Use the existing text artifact and criterion responses for the first rehearsal. A graphical atom-builder/exporter would be additional implementation.
9. **Review and resume.** Saving a draft retains work; it does not claim mastery. Keep the unit, source version, question history and artifact connected. Returned teacher feedback is separate from the student's self-review. Continue to the next sourced objective only through its real saved state.

Proposed three-criterion rubric: **accurate labels and configuration**, **reason connecting configuration to period/group**, **supported comparison and explicit model limitation**. Completion must use the existing required artifact work, milestones and criterion checks; do not bypass those checks for the demo.

## Visual and human design

The active page should contain one objective, one useful visual, one concise explanation and one next action. Put source detail, history and extensions in labelled disclosures. On desktop, align the visual with its explanation; on phones, stack the visual above controls with a readable table alternative. Follow the frontend's existing type, spacing, focus, button and reduced-motion system. Reuse Visionary Guide and its own illustration vocabulary; chemistry diagrams should be code-native and labelled.

3D is useful for inspecting a schematic shell model, but the table and trend charts work better in 2D. Label an atom view **Schematic shell model - not to scale**. Do not suggest electrons physically travel on these fixed rendered paths, animate continuous orbital motion as scientific fact, or let camera rotation count as learning evidence. Pause/reset and equivalent text controls must work without pointer gestures, motion or WebGL. Low-bandwidth mode should preserve the objective and explanation, not replace the lesson with a loading screen.

The book's table p2 is rotated on the scan. Rebuild the reviewed demo selection as an upright accessible table instead of embedding that unreadable image into the lesson. Color can assist comparison, but selected group, period, shell count and element labels must be available in text.

## Source review before authoring

- The source p2 uses temporary symbols such as Uut, Uup, Uus and Uuo. Current teaching should use a separately reviewed modern table. IUPAC approved Nh, Mc, Ts and Og for elements 113, 115, 117 and 118 in 2016. [IUPAC naming announcement](https://iupac.org/iupac-announces-the-names-of-the-elements-113-115-117-and-118/). Preserve the original scan and identify any adapted correction.
- The chapter uses a simplified shell treatment. Restrict the first demo to reviewed main-group examples, rather than applying its outer-electron shortcut to every transition element.
- The electron-affinity discussion pp12-13 presents released energy alongside negative electron-gain values. Choose and label one convention consistently; compare magnitude and sign explicitly. [IUPAC definition](https://old.goldbook.iupac.org/html/E/E01977.html). Ionization energy and electronegativity should have separate contexts and labels.
- Trend arrows must say **generally** and retain relevant exceptions. The source itself flags ionization exceptions p12 and F/Cl and O/S affinity exceptions p13. Avoid scoring a universal trend assertion as correct.
- Nuclear examples need a specified isotope and charge. The source p15's observations about mass number are not a universal formula for generating A from Z. For a neutral atom, electron count equals Z; for an ion it changes with charge. Review any correction before publishing.
- The family comparison includes reactive metals and halogens. Use virtual representations in this frontend demo; do not turn them into unsupervised physical reaction instructions.
