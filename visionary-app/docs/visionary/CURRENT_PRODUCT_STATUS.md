Never imply real AGI or invent progress.

**Design acceptance remains open.** The first Ask composer, authored learning unit and populated Build editor now have desktop/intermediate/mobile captures; the learning stage indicator is clearer, and voice-to-text fallback closes its panel. Inspect failure states, Build sharing and role tools.
