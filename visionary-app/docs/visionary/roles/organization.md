## Connected acceptance and metrics

OR-F1 accepted teacher links class → reviewed activity assigned → learner submits → teacher returns → authorized org view derives from same records. Private personal learning is absent from service responses, not merely hidden in UI.

OR-F2 membership/permission change updates scoped controls, notifications and audit; stale requests cannot reintroduce data after revocation. Deactivation preserves personal portable history and assignment record retention policy.

OR-F3 authoritative Class 5→6 event commits all mappings before teacher/parent/org audience views change. Original open assignments retain stage/version. Undo restores exact prior active mapping and keeps a separate audit/history of later work. Boundary changes require authorized confirmation.

OR-F4 school and company administrator scenarios show different vocabulary and eligible controls through service stage/context profiles, not separate applications. Analyst cannot change policy; billing admin cannot inspect learning transcripts; teacher cannot manage global permissions.

Metrics use accepted people, scoped assigned work and objective coverage with explicit denominators/periods; never personal engagement surveillance or inferred ability rankings. Fixture approval requires all permission roles and lifecycle/error cases, small-group suppression, linked vs independent classes, and transition consistency. Current fixtures are a starting point, not full governance acceptance.
