## 0. Executive brief (corrected product-manager statement)
Visionary is a pedagogical intelligence ("pedagogical AGI" internally; customer-facing name: **Visionary Guide**) that teaches, checks, practices, and builds with any person — student, teacher, parent, professional, organization — in the language they think in, across a lifelong journey.
The product is NOT: a blank chat interface, an answer generator, a recorded-course catalogue, a school-only LMS, a teacher replacement, or a marketplace-first product.
The signature experience is the **guided learning loop**: set goal → check prior understanding → teach with the best representation (3D/diagram/simulation/audio/text/worked example) → interrupt with a doubt without losing place → check understanding with evidence → practice over time → build something real → reflect and continue.
Every screen must answer: *What should I do now, why, and what happens next?* — with ONE obvious next action.

## 2. Anti-chatbot doctrine (why v1 failed — mandatory corrections)
| v1 failure | v2 requirement |
|---|---|
| Blank textarea heroes; "Ask AGI" floating on every screen | No screen opens with an empty input. Ask is a **guided studio** with intent-first entry; label is **Ask Visionary**; ONE contextual Ask action per page where it relates to content; max ONE floating action per screen, only when Ask is the highest-priority action |
| Chat-bubble lesson experience | Lesson is a **player**: stage rail (Explain→Explore→Try→Check→Reflect) + learning canvas + Guide panel. Doubts pause and resume at exact position |
| Dashboard of every metric | Home is a decision surface: ≤5 modules, one obvious next action, "Why this?" on every recommendation |
| Percentages as truth | Named mastery stages (Not started, Exploring, Practicing, Secure, Mastered, Needs review); numbers secondary with "How is this calculated?" |
| Blurred locked projects | Transparent prerequisites: preview, "View prerequisite," explore where safe |
| ₹199 hard-coded | ₹299 from plan fixture/config only |
| Mixed confidence/mastery/completion | Four distinct metrics: completion, accuracy, mastery stage, learner self-reported confidence. System certainty never shown as learner confidence |
| Generic speech-bubble art | Subject-semantics illustration grammar or neutral placeholders; decorative art hidden from assistive tech |

## 5. Roles — deep product spec
### 5.1 Student
**Home (decision surface, ≤5 modules):** Continue (exact resume of lesson/practice/project or highest-priority next) · Today plan (≤3 sequenced items, total time, editable) · Needs attention (≤3 evidence-backed gaps with reason+action) · Subjects strip (stage badge, next activity, review due) · Build opportunity (1 project tied to secured concepts). Connected-org row when present. Rules: no upsell lead, no shame, zero = "No evidence yet", "Why this?" everywhere, "Change plan" action.
**Learn:** compact context switcher (Board · Class/Year · Term/Goal); subject cards (next objective, mastery stage, review due, assigned marker, Continue); add/remove/reorder subjects + syllabus upload placeholder; curriculum vs personal-goals view. Subject detail: header (goal, source/version, estimated effort, progress explanation), chapter/unit sequence with prerequisite states, resume card, bookmarks, mastery map (graph + accessible list), filters (All/Next/Needs review/Assigned/Bookmarked/Completed). Objective detail: outcome statement, prerequisite quick-refresh, available representations, evidence so far + what's needed, Start/Resume + contextual Ask/Practice/Build, attribution, Report an issue.
**Lesson player (signature):** desktop = breadcrumb/objective/session progress/save-exit top; stage rail left (Explain, Explore, Try, Check, Reflect); interactive canvas center (3D/diagram/simulation/text/worked example); Guide panel right (explanation, transcript, vocabulary, notes, Ask); bottom bar (audio, captions, language, speed, reset view, prev/next). Compact = canvas first, Guide below/sheet, stage progress visible, no hover-only controls, optional reversible fullscreen 3D. Behavior: save position every meaningful step; Ask pauses preserving time/stage/canvas and attaches question to objective; answer = direct clarification → smaller example → alternative representation; "That makes sense" resumes exact point, "Show another way" switches representation, "I'm still unsure" starts prerequisite remediation; in-teaching checks with feedback+retry (no red failure pages); session ends with retrieval, confidence self-report, summary in learner language, next practice time, optional build link; notes/bookmark/transcript/captions/keyboard/reduced-motion/2D-text alternative. 3D never spins forever: Retry / Switch to 2D / Read explanation / Download for later.
**Ask studio:** entries = continue from lesson · ask about subject/topic · upload/paste item placeholder · ask outside curriculum. New question first asks intent: understand · solve with guidance · check my attempt · plan learning · build. Responses use steps, questions, visuals, checks. Active-assessment/graded context defaults to hints+reasoning. Modes: Teach me / Give me a hint / Check my attempt / Practice a similar problem / Help me plan / Explain the feedback. History grouped by goal/topic; delete/export/rename/detach from personalization. Fixture answers carry a visible "Demo response" dev indicator.
**Practice:** today review queue from due objectives; start quick practice / exam simulation / teacher assignment / custom set; topic cards (last attempt, retention due, common error, best next action); one task at a time with language/accessibility controls + flag; feedback distinguishes concept / process / careless / uncertain; results show evidence, correction, next review date, recommended lesson (not only score); attempt history + answer review; "Re-practice" explains why.
**Build:** one recommended project tied to current objectives; explorable catalogue (subject/skill, level, time, tools, output filters); My projects (Draft, In progress, Feedback, Completed, Shared); transparent prerequisites with preview/explore (strict gates only for safety/expensive tools); workspace = brief + success criteria, milestones/checklist, central creation surface (code/canvas/document/model/presentation/experiment fixture), live preview pane, Ask with project context, concept links back to Learn/Practice, version history, autosave, reflection, export, sharing permissions; teacher/peer feedback only when explicitly shared. Never promise "uncopyable": access control, watermarking, licensing, limited downloads, version tracking, takedown/reporting.
**Progress:** explainable model = mastery stages + activity completion + practice accuracy over time + retention status + learner-reported confidence + projects/demonstrated skills + org assignment status. Every metric has "How is this calculated?" + time range. No class rank. "Exam readiness" must state scope/coverage/date/uncertainty else label "Practice coverage".
**Connected organization space:** named workspace tab containing only that relationship: Overview, Classes/subjects, Assigned work, Schedule, Teacher feedback, Announcements, Shared resources, Organization progress. Personal learning never silently merged into institution reporting.
**Lifelong transition:** never auto-promote by date alone. Show "Your next stage is ready", explain detected change + source, allow confirm/edit/postpone (user or authorized org), archive previous curriculum without deleting progress, map prerequisites, carry mastery evidence, create bridge plan.
### 5.2 Teacher
Home: next class/lesson to prepare · learners needing attention (evidence + privacy-safe reasons) · assignment review/feedback queue · class progress changes · own upskilling plan · recent resources/artifacts · org announcements · marketplace secondary only.
Prepare / Lesson Studio: create from curriculum/topic/objective/file placeholder/custom goal; context (class/age/level/language); objective + prerequisite review; fixture-generated outline; representations + activities; likely misconceptions; checks + rubric; differentiation variants; accommodations; time plan; source & accuracy review; **Preview as learner**; save to library / assign / share. Generated material always editable, attributed, explicitly reviewed before assignment — Visionary assists, never replaces teacher control.
Classes: cards (next session, outstanding work, learners needing support, recent activity); detail tabs Stream/Lessons/Assignments/Learners/Insights/Schedule/Settings; assignment composer from lesson/practice/project/resource with due date, audience, language, difficulty, rubric, accommodations, collaboration flag; lifecycle Draft→Scheduled→Active→Closed→Returned.
Learners: roster + group views; filters (class, objective, review due, missing work, requested help); detail limited to authorized org scope: evidence timeline, misconceptions, assigned work, feedback, recommended action. **Never private personal questions** unless learner shared or documented safety policy.
Insights · Teacher Growth (own Learn–Ask–Practice–Build loop, separate from admin) · Build/Library (version, duplicate, preview, share, export; ownership/license/source; org resources inherit org policy).
Marketplace (feature-flagged, later service, complete frontend): seller eligibility + adult verification placeholder; listing composer (title, audience, outcomes, preview, language, price, license, accessibility, source declaration); moderation states Draft/Submitted/Changes requested/Approved/Rejected/Suspended; buyer preview/license/refund/rating integrity/report; earnings itemized: list price, discount funder, tax, refunds/chargebacks, processing fee, **30% Visionary commission**, net payout, payout date/status; takedown + appeal states.
### 5.3 Parent/Guardian (clarity & support, never surveillance)
Home: child switcher with connection status · weekly plain-language summary · what is going well · what needs support and why · upcoming work/transitions · teacher/org update · ONE realistic non-punitive suggested action · Ask about child's learning context.
Child report tabs: Overview / Learning progress / Practice & retention / Projects / Organization work / Teacher updates / Goals & transitions. Every insight shows evidence period + source. No opaque risk scores; language like "may need a refresh based on two recent attempts", never "weak student".
Connections: Pending/Active/Declined/Expired/Removed child relationships; connected teachers/orgs with scope + who approved; invite/approve/remove; notification frequency (urgent/daily/weekly/off) + language; data-sharing summary + consent history.
Parent Ask intents: How can I help this week? · What does this progress mean? · Which questions should I ask the teacher? · What should we consider before a class/board/college/location change? · Compare education options by budget/location/requirements/goals (research workflow + source placeholders, never fabricated results).
Boundaries: no default access to private doubts/notes/drafts/personal goals; no public child comparisons; no streak-loss alerts framed as misconduct; payer ≠ guardian automatically; teens get age-appropriate transparency + increasing control.
### 5.4 Professional
Home: current goal + next best action · skill map with evidence/gaps · work/project continuation · practice/interview review due · career milestone · employer-assigned activity in clearly marked org section.
Learn/Ask/Practice/Build variants: learn from role goal/certification/domain/uploaded source placeholder/work problem; Ask = explanation, guided problem solving, critique, planning, brainstorm; Practice = scenarios, simulations, recall, interview tasks, skill checks; Build = portfolio/workplace artifacts with confidentiality controls.
Career: target role/skill plan · evidence-based gap analysis · portfolio artifacts · interview practice · milestones + reflection · current-source placeholders for jobs/certifications/market (never fabricate live opportunities).
Employer connection: personal/work workspaces visibly separate; employer sees only assigned activity, submitted artifacts, agreed skill evidence; warn before moving/sharing personal artifacts into employer workspace; confidentiality warning before company-sensitive content.
### 5.5 Organization Admin
Overview: setup checklist when new; active people/cohorts; activity + assignment completion; objectives needing attention; teacher adoption/preparation; data-quality notices; plan/seat usage; recent admin actions. **No vanity graph without an action.**
People: learners/teachers/guardians/professionals/admins; invite, bulk-import placeholder, join code, deactivate, transfer cohort, resend; clear status + identity source; least-privilege roles Owner/Billing Admin/Org Admin/Academic Admin/Teacher/Viewer-Analyst.
Cohorts: create/manage classes/batches/departments/teams; assign leads+members; term/schedule/framework; archive lifecycle; org announcements + resources.
Curriculum/Content: select board/track/framework + version; map org subjects to Visionary objectives; local content placeholder with review status; assign lesson/practice/project templates; approval + source audit.
Insights: cohort objective coverage, retention due, assignment status, teacher activity, adoption; drill-down only within authorization; small groups suppressed/anonymized; export placeholder with scope/purpose/expiry.
Settings & governance: profile + verified domains; roles/permissions; guardian & minor policies; data-sharing & retention; AI/model feature controls placeholder; allowed languages & curriculum sources; marketplace/content policies; billing admins + invoices; audit log (actor, action, target, time, outcome).
