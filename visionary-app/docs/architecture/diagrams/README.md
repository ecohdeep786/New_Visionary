Reproduce from the product root using existing frontend Puppeteer and a cached, version-pinned Mermaid renderer:

```powershell
node scripts/architecture-review-layout.mjs
node scripts/render-architecture-diagrams.mjs PLATFORM_ARCHITECTURE REQUEST_PATHS RESILIENCE_AND_SCALE SYSTEM_OVERVIEW LEARN_TEACH BUILD_SYSTEM BUILD_LIFECYCLE LEARN_BUILD_BOUNDARY
```

The renderer fetches public Mermaid 11.12.1 on its first run and writes a local hash/dimension manifest under ignored `artifacts/tmp/architecture-diagrams/`. Markdown contains the logical Mermaid sources. Platform/resilience exports use native SVG layouts under `source/`, generated by the layout script, to preserve a compact grid and readable group labels; their logical companions are also parsed. SVG provides zoomable labels and PNG supports quick review. The [Build reference study](../../../research/BUILD_REFERENCE_STUDY_2026_10_16.md) and [YouTube-page review](../../../research/YOUTUBE_REFERENCE_REVIEW_2026_10_16.md) distinguish observations, inferences and unknown private internals.
