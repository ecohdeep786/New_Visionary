This is the current implementation inventory for a real-user product. It is not a hosted release certificate. The machine-readable inventory contains each declarative control, event expression, location, source digest, possible route reachability and conservative review profile. Repeated/map-rendered controls are one source declaration; runtime instances depend on data. Import reachability over-approximates conditional rendering. ## Meaning of the states

- **connected:** implemented client interaction or configured server code path. Check execution type and endpoint evidence; this word alone never means hosted, paid/live, curriculum-qualified or safe for a particular user.
- **preview:** a browser-local/domain rehearsal path. Real identities, object permission and cross-device persistence still require the linked server work.
- **missing:** a required service/adapter or delivery integration is absent from the selected runtime. Existing loading/unavailable states remain part of the journey.
- **intentionally-unreleased:** development-only or retained source without a route-import path. It must not be advertised as an exposed capability.

Classification is conservative at the source-file/operation boundary: form inputs and shared UI widgets inherit their reviewed caller boundary; no static analysis claims to prove arbitrary event callback behavior. Mixed pages have separate operation records below. A local toggle or UI control cannot certify the server operation it prepares.

## Roles, categories, languages and admission

Five roles: student, teacher, parent, professional, organization. The route table uses the current navigation allowlist; class/guardian/org/source/consent checks remain separate server requirements.

Category scenarios: primary, secondary, higher-secondary, competitive, vocational, higher-education, independent-adult, professional, employer-sponsored. Evidence: synthetic category acceptance tests and current stage presentation. These scenarios are not an approved content catalog.

Internal interface/teaching locale types: en, hi, bn. Interface, teaching, input, source medium and published edition are separate dimensions. Public pages contain English copy. Onboarding choices are English, Hindi, Bengali, Tamil, Telugu, Kannada, Malayalam, Marathi, Gujarati, Punjabi, Urdu, Odia, Assamese, Others; choices beyond the current locale types require SCOPE-02/AI-18 qualification. Selecting a label never establishes source/provider coverage.

Current presentation stage keys: primary, secondary, higher-secondary, competitive, vocational, higher-education, independent, professional. The nine category scenarios use independent-adult → independent and employer-sponsored → professional; a fixture alias is not an additional model or curriculum. Teacher contexts are school/higher_ed/university/coaching/independent; organization onboarding contexts are school/college/university/coaching/training. Parent access needs a separately verified child relationship; professional and employer-sponsored work preserve personal/work boundaries.

Current connected admission is adult-only; minor personas are fictional test scenarios. Onboarding role labels and browser preview links are not verified classroom/guardian/organization membership. Guardian-first access remains an open launch gate.
