## B. Verified defect found and corrected (1)

**F-14-F1 (P3 → fixed; closes F-02-F3): the landing hero's raw `<img>` used camelCase
`fetchPriority`, triggering the React 18.2 dev-console warning.** `NewPersona.jsx:380,440` passed
`fetchPriority="high"` directly to DOM imgs (the F-02-F3 recorded warning — reproduced live this
run). The fix applies LazyImage's own A4-receipted treatment: a spread passthrough
`{...{ fetchpriority: "high" }}`, which reaches the DOM as the standard lowercase attribute while
sidestepping both the React warning AND the `react/no-unknown-property` lint rule (spreads are not
literal-attribute checks). Verified live after the fix: **5 hero images carry
`fetchpriority="high"` in the DOM, zero console issues**; lint exit 0. The intermediate
lowercase-literal form was caught by the lint rule and corrected to the spread form in-lane — the
guard chain (lint → inventory digest → battery) worked exactly as designed.
