3. **[P1] Idempotency digest excludes the command being executed.** `workspace.repository.ts:146,171` hashes `input.payload ?? {}` instead of canonical name/slug/description/personal fields. A retry using the same command/slug and changed name, with no separate payload, is accepted and returns the old workspace instead of rejecting the changed command. Derive the digest from the validated actual command, bind it to operation/actor/scope, and return its recorded committed result. Verify sequential and concurrent same/different payload retries on the actual repository.

4. **[P1] Invitation consumption is not atomic.** `workspace.repository.ts:219` reads an ISSUED invitation outside the transaction; `:229` unconditionally updates by ID. Two callers can both pass the read and create memberships for different UIDs from one token. Claim the still-valid invitation conditionally within the transaction, require exactly one winner, and make retries explicit. Test accept/accept and accept/revoke races against a transaction-capable adapter. The included scheduling probe demonstrates both accepted accounts; it does not claim real PostgreSQL isolation was tested.

5. **[P1] Unknown membership roles fail open.** `workspace.repository.ts:54` compares an undefined rank with the required number. The result is false, allowing an unrecognized stored role to satisfy ADMIN. The submitted SQL permits arbitrary role TEXT. Explicitly reject unknown roles and enforce a matching SQL enum/check constraint; test corrupted/unknown roles against the actual class.

6. **[P2] Millisecond strings are not unique ordered replay cursors.** `workspace.repository.ts:190,261` assigns `${Date.now()}` and the DDL only indexes `(uid,cursor)`. Same-millisecond events share a cursor and can be lost by cursor-only replay. Define a durable per-scope ordering/tie-breaker compatible with the accepted observation contract, and test collisions/restart/replay. Do not claim ordering merely from a NOT NULL column test.

7. **[P1] Required import-provenance verification fails.** `node scripts/verify-imports.mjs` exits 1 with `Imported source changed: backend/upstream/backend/prisma/schema.prisma. Record an intentional patch before accepting it.` Record and verify the intentional upstream schema/app changes using the repository's existing patch mechanism, then rerun relevant checks.
