## Defect (T03 research walk, recorded in Jira on the live product walk)

The create-a-class journey painted its same-intent primary controls from **three paint systems**. Measured in-page (getComputedStyle; contrast per the house alpha-compositing WCAG math; HIG Color was studied live in the browser: "Avoid using the same color to mean different things. Use color consistently throughout your interface, especially when you use it to help communicate information like status or interactivity."):

| control in ONE journey | paint at beta `5a9190e3` |
| --- | --- |
| header "Create class" (`v-button primary`) | token action — light `#0071e3`, dark remap `#aac7ff` |
| empty-state CTA "Create your first class" (`TeacherHome.jsx`) | **inline** `background-color: accent` = `#0b57d2` (default theme), `#137333` when the account accent is green |
| modal submit "Create class" | **inline** `background-color: accent` (same values), `h-10 rounded-full` pills |
| modal Cancel | **hardcoded** `text-[#0b57d2]` (follows neither token nor accent) |
| modal field focus | **hardcoded** `focus:border-[#4285F4] focus:ring-[#4285F4]` (legacy Google blue) |
| dark mode | the token block remaps; the inline/hardcoded paints do **not** — Cancel `#0b57d2` over the dark dialog surface measured **2.69:1**, below the product's own 4.5:1 informative law (FAP-30) |

The account accent is a first-class user path (Settings → Account appearance); a teacher who had picked green met, in one journey: settings-save `#0071e3` (token) → empty CTA `#137333` → dialog submit `#137333` **next to** Cancel `#0b57d2` in the same dialog → populated header `#0071e3`.

## 2. The change (two source files)

- `frontend/src/components/dashboard/teacher/CreateClassModal.jsx`: the submit adopts the design-system primary classes (`v-button primary` — token paint, hover/disabled/focus states come from the system; no inline `backgroundColor`); the Cancel adopts the secondary classes (`v-button`); the fields' focus paints from the action token (`focus:border-[var(--v-action)] focus:ring-1 focus:ring-[var(--v-action)]`, the product's established input pattern); the `accent` prop is removed from the component.
- `frontend/src/pages/dashboard/role/TeacherHome.jsx`: the empty-state CTA paints `v-button primary` — one token language across both states of the create entry (per-state singleton law unchanged, FAP-78); the `accent` prop is removed from the `CreateClassModal` call site; the component doc comment documents the color law.
- Untouched by design (color-tokens-only change): copy, creation flow, field geometry, the class-color choices `COLORS` fieldset (data, not chrome), `AssignLesson`'s own dialogs, the FAP-78 per-state law and the `?create=1` deep link.
