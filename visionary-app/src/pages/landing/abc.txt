## Master Prompt: Google-Inspired Page Redesign Project

Review the **entire existing product and all current pages first** before making any changes. I have updated files recently, so always work from the latest version of the project.

Your goal is to improve the product’s public-facing pages so they feel as polished, structured, trustworthy, accessible, and consistent as Google’s web experiences—while still preserving our own product identity, content, and functionality.

Do **not** simply copy Google text, add a Google-like illustration, or make superficial visual changes. Study the referenced pages deeply: their layout systems, navigation, hierarchy, spacing, typography, cards, content flow, responsive behavior, calls-to-action, accessibility patterns, trust signals, footer structure, and visual storytelling. Then adapt those principles appropriately to our current product.

The final product should feel like a premium, modern, Google-quality experience with a consistent design system across all pages.

## Core Working Rules

1. **Start by auditing the current product**
   - Review all existing pages, components, layouts, styles, navigation, footer, responsive behavior, images, and content.
   - Identify what has changed in the latest files before editing anything.
   - Understand the current design system before proposing or implementing improvements.
   - Do not remove working functionality unless it is intentionally being replaced with a better version.

2. **Work on one page at a time**
   - Complete one page fully before starting the next page.
   - Do not partially redesign multiple pages at once.
   - For each page, first review our current implementation, then study every related reference link listed for that page.
   - Only move to the next page after the current page is complete, polished, responsive, and consistent with the overall product.

3. **Study reference pages deeply**
   - Inspect the reference pages carefully, not only their text or hero section.
   - Analyze:
     - Header and navigation behavior
     - Hero composition and messaging hierarchy
     - Typography scale and line length
     - Grid, spacing, alignment, and whitespace
     - Card patterns and section composition
     - Image, icon, illustration, and visual storytelling approach
     - CTA placement and button hierarchy
     - Interactive elements
     - Trust, privacy, safety, and credibility signals
     - Mobile and tablet layout behavior
     - Accessibility and readable contrast
     - Footer structure and legal navigation
   - Use Google’s design quality and structural thinking as inspiration, but create an original implementation for our brand and product.

4. **Maintain one unified product design system**
   - Use consistent typography, color usage, spacing, buttons, cards, form controls, icons, section patterns, and animations across all redesigned pages.
   - Every page should feel like part of the same product—not like separate templates.
   - Improve the global header, global footer, responsive navigation, and reusable UI components when necessary.
   - Ensure all pages work well on desktop, tablet, and mobile.

5. **Use images intentionally**
   - Add or improve images, illustrations, icons, diagrams, screenshots, and visual assets where they improve comprehension or trust.
   - Do not use decorative visuals only to fill empty space.
   - Each visual should support the page’s message, product story, feature explanation, safety concept, or user action.
   - Use an original, consistent visual style throughout the product.
   - Optimize images for performance and provide meaningful alt text.

6. **Focus on real page improvement**
   - Do not treat this as a text rewrite.
   - Do not only add a hero illustration and consider the page complete.
   - Improve the complete experience: structure, content hierarchy, clarity, interactions, usability, responsive behavior, design quality, and conversion flow.
   - Each redesigned page should be noticeably more thoughtful, modern, clear, and trustworthy than the current version.

7. **Completion checklist for every page**
   Before moving to the next page, confirm that:
   - The current page was reviewed first.
   - Every assigned reference link was reviewed.
   - The page structure was improved, not only the copy.
   - The design aligns with the shared product system.
   - The page is responsive across desktop, tablet, and mobile.
   - Accessibility was considered, including contrast, keyboard navigation, focus states, semantic structure, labels, and alt text.
   - Images and icons support the content.
   - CTAs are clear and logically placed.
   - The page is visually polished and production-ready.
   - Header, footer, and navigation remain consistent.

***

## Required Workflow for Each Page

Follow this exact process for **every page**:

1. Open and inspect the current page in our product.
2. Review the latest related files and components.
3. Identify the current page’s weaknesses, missing sections, inconsistent components, and usability issues.
4. Visit and study each Google reference link assigned to that page.
5. Extract the useful design principles, information architecture, section order, interaction ideas, visual patterns, and trust-building elements.
6. Plan how those principles can improve our product without copying Google’s content or branding.
7. Redesign and implement the page completely.
8. Add or improve relevant images, illustrations, icons, diagrams, and visual assets.
9. Test the page for responsiveness, accessibility, consistency, and visual quality.
10. Review the completed page against both:
   - Our existing product design system
   - The quality, clarity, and structure of the Google reference pages
11. Only after the page is complete, move to the next page.

## Final Quality Standard

The redesigned product should not look like a collection of basic pages with extra text and illustrations. It should feel like a complete, intentional, high-quality product website.

The final result must:

- Have a consistent visual language across every page.
- Use thoughtful layouts inspired by the quality and structure of Google’s pages.
- Preserve our own product identity rather than copying Google branding.
- Be modern, polished, responsive, accessible, and easy to navigate.
- Use purposeful imagery and clear visual storytelling.
- Improve information architecture, not only visual styling.
- Include strong hierarchy, readable content, clear CTAs, and user-focused journeys.
- Make users feel confidence in the product’s privacy, safety, security, support, accessibility, and company credibility.

Start with the **AboutUs Page**. Complete it fully using the workflow above, including all assigned reference links, before moving to the **Privacy Page**. Continue in the exact order listed until all pages and the global footer are complete.
