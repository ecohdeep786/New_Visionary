# Local development artifacts

Retained during relocation:

- `tmp/`: previous root temporary logs, screenshots, diagnostic scripts and typography evidence.
- `legacy/root/`: prior root audit JSON and scratch images.
- `legacy/scripts-tmp/`, `legacy/dev/`: previous scratch directories.

Local/generated artifacts are ignored by Git. Previously tracked reports and scratch evidence have explicit tracking exceptions so relocation does not silently remove them from version control. Deliberate acceptance evidence remains in `docs/visionary/baseline/`. Write new temporary reports under `artifacts/tmp/`; save shareable evidence in its documentation handoff. Retained legacy diagnostic scripts can contain historical paths; use current component scripts for new checks.
