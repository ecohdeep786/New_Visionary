# Frontend working notes

Read the product root's `AGENTS.md` and this package's `README.md`. Preserve current page/component/service/domain conventions and unrelated public typography work.

Use `src/` for code, `public/` for assets, `tests/` for regressions and `scripts/` for rendered checks. Root npm commands delegate here. Run lint, both types, relevant tests and the production build for changes. Browser-local preview authorization cannot substitute for server authority when connecting live adapters.
