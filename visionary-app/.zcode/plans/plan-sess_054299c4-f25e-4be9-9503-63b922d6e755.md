## Plan: Consolidate font source + clean up frontend page files

### Goal
1. Make all frontend (public landing) files reference the single font source in `src/styles/` — eliminate the 28 duplicated `const FONT` / `FONT_FAMILY` constants.
2. Remove temporary/unnecessary files from the frontend page scope only — do NOT touch the dashboard/internal product directory.

### What I found
- `fontStack` in `tokens.js` is defined but **completely unused** — no file imports it.
- **28 landing files** each declare their own `const FONT` / `const FONT_FAMILY` with the identical string `'Google Sans Flex', 'Google Sans', sans-serif`.
- `VisionaryLogo.jsx` (line 28) hardcodes an inline `fontFamily` string — shared scope (used by both landing nav and dashboard).
- **All 5 CSS files** in `src/styles/` are already imported by `index.css` — no orphaned/temp CSS files there.
- No temp/unused files currently found in `src/styles/`.

### Implementation steps

**Phase 1: Establish the single font source in `src/styles/`**

Create `src/styles/tokens.css`:
```css
:root {
  --font-brand: 'Google Sans Flex', 'Google Sans', sans-serif;
}
```
Import it in `index.css` alongside the other style layers. This becomes the canonical font source in the `src/styles/` folder, accessible via CSS variable by all CSS files.

**Phase 2: Update `tokens.js` to re-export the brand font**

The `fontStack` export already exists and is correct:
```js
export const fontStack = "'Google Sans Flex', 'Google Sans', sans-serif";
```
It stays as the JS mirror for inline-style consumers.

**Phase 3: Replace all duplicated constants in frontend page files (28 files)**

For each of the 28 landing files in `src/components/landing/` and `src/pages/landing/` and `src/pages/Landing.jsx`:
- Replace the local `const FONT` / `const FONT_FAMILY` declaration with an import:
  ```js
  import { fontStack } from "@/components/landing/system/tokens";
  ```
- Replace all inline `style={{ fontFamily: FONT }}` / `style={{ fontFamily: FONT_FAMILY }}` with `style={{ fontFamily: fontStack }}`.

Also fix `VisionaryLogo.jsx` line 28 to import `fontStack` instead of hardcoding the inline string.

**Phase 4: Remove temporary files from frontend page scope only**

I will check for and remove any temp/scratch files in:
- `src/pages/landing/`
- `src/components/landing/`
- `src/pages/`

NOT touching:
- `src/components/dashboard/`
- `src/components/ui/`
- `src/lib/`
- `src/services/`
- `src/hooks/`
- `src/data/`
- `src/domain/`

**Phase 5: Validate**
Run `npm run lint`, `npm run typecheck`, and `npm run build` to confirm no breakage.
